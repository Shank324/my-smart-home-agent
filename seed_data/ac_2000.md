# AC-2000 智能空调

## 设备概览

AC-2000 是一台壁挂式变频空调，适用面积 12 至 20 平方米，额定制冷量 3500W，制冷剂 R32。
支持制冷、制热、除湿、送风四种运行模式，可通过家庭网关、移动端或场景联动控制。
设备内置温度传感器与压缩机保护逻辑，异常时会停机并在面板显示故障代码。

## 运行模式与适用场景

**制冷（cool）**：夏季常规使用，设定温度范围 16 至 30°C。
**制热（heat）**：冬季使用，室外低于 -7°C 时制热效率会明显下降。
**除湿（dry）**：湿度高、体感发黏时使用。除湿模式的风量偏小、制冷量降低，
目的是把空气中的水分凝结排出，比一味调低温度更省电，也不容易让人半夜着凉。
**送风（fan）**：仅循环室内空气，不制冷也不除湿，适合春秋过渡季节。
模式冲突是常见报错原因：同一台设备不允许同时处于制冷和制热状态。

## 温度与湿度建议

夏季建议设定 24 至 26°C，与室外温差不要超过 7°C，否则进出房间容易不适。
冬季建议 20 至 22°C，每提高 1°C 大约多耗 6% 至 8% 电。
室内相对湿度高于 65% 时体感会明显发黏，此时优先用除湿模式，目标湿度 50% 至 60%。
夜间睡眠建议 26°C 配低风速，避免直吹。

## 常见故障代码

| 代码 | 含义 | 常见原因 |
|---|---|---|
| E1 | 压缩机高压保护 | 冷凝器前方有遮挡、室外环境高于 43°C 仍强制制冷、控制回路异常 |
| E2 | 压缩机低压保护 | 冷媒不足、过滤器半堵 |
| E3 | 蒸发器防冻结保护 | 室内风机不转、出风口被堵、室内低于 18°C、感温管插头松动 |
| E4 | 压缩机排气管温度过高 | 压缩机老化、外机散热不良、冷媒偏少 |
| E5 | 过电流保护 | 电压异常、压缩机绕组异常、电容失效 |
| E6 | 通讯故障 | 室内外机连接线松动或断裂、通讯板故障 |
| E7 | 模式冲突 | 同时下发制冷与制热指令 |
| E8 | 防高温保护 | 制热时内机温度过高，多为滤网堵塞 |
| E9 | 防冷风保护 | 制热刚启动时的正常保护，通常几分钟后解除 |
| F1 | 室内环境感温包开路或短路 | 感温包线束松脱、感温包损坏 |
| F2 | 室内蒸发器感温包开路或短路 | 同上，位置在蒸发器翅片附近 |
| F3 | 室外环境感温包开路或短路 | 外机接线端子进水或氧化 |
| F4 | 室外冷凝器感温包开路或短路 | 外机散热不良导致长期高温，加速老化 |
| F5 | 室外排气感温包开路或短路 | 需检测外机排气温度传感器 |

出现 E1 至 E5 这类压缩机保护代码时，先断电 10 分钟再上电重试一次；
重复出现说明是硬件问题，应报修而不是反复重启。E9 属于正常启动过程，不必处理。
F 类代码一般不影响短时间使用，但会导致温度控制不准，建议一周内安排检修。

## 无法启动的排查顺序

1. 确认设备在线状态。离线说明网络或网关断开，先检查家中其他设备是否也不在线。
2. 确认电源。检查空调专用空气开关是否跳闸，配电箱对应回路是否合上。
3. 确认遥控权限。场景锁定或其他账号占用时，本机指令会被拒绝。
4. 观察面板是否有代码显示。有代码按上一节对照处理。
5. 完全无反应（面板不亮、无提示音）多为供电问题，不要自行拆机。
6. 若在制热模式刚启动，等待 3 至 5 分钟，防冷风保护会自动解除。

## 制冷或制热效果差的排查

- 滤网积灰是最常见原因，建议每 2 周清洗一次，用清水冲洗后阴干再装回。
- 检查出风口是否被家具或窗帘遮挡，室内机前方至少留出 30 厘米。
- 外机周围 50 厘米内不要堆放杂物，散热片积尘可用软毛刷清理。
- 门窗密封差会导致冷量流失，温差始终上不去。
- 上述都正常仍无明显效果，可能是冷媒泄漏，需要专业检测，不要自行加注。

## 保养与使用注意

换季停用前，选送风模式运行 2 小时把机内吹干，避免发霉。
长期不用时拔掉插头或断开空气开关。
清洗滤网必须断电后进行，不要用水直接冲洗室内机本体。
室外温度低于 -7°C 或高于 43°C 时，压缩机保护会导致能力下降，属于正常现象。
